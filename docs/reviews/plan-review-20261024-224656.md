## Findings

No blocking or material findings. One Low precision finding:

- **F-1 (Low) — Stage scoping of doc-marker validation is underspecified.** Plan §7.4 (L673-681) requires the three doc marker blocks (`protocol-message-map` / `protocol-event-map` / `protocol-identity-map`) to be compared row- and field-exactly against the model, and the fixed s1 output line (L722-729) asserts `event_types=11` with `doc_missing=0`. However §8.2 (L759) says S1 creates "doc 三个标记块（S1 部分）" and does not list the event registry/payloads among S1 changes, while S2 (L775) owns "11 个 event payloads". The plan never specifies whether the validator is stage-aware (skipping or partial-matching event-map payload fields at `--stage s1`) or whether S1 must already carry complete payload rows (which would make the S2 payload work descriptive rather than incremental). This is an implementation-ambiguity defect in the validation contract, not a protocol-design defect; it is resolvable without changing any message, state or slice boundary. Destination: A2 implementation S1 — resolve by making the stage gating explicit in `docs/16`/`validate.mjs` before fixtures are frozen.

Special-lens observations (not findings):

- **Goal-bound minimal design**: every proposed surface (11 event types, 12 messages, 22 identities, 9 endReasons, 10 quarantine reasons, IVR-local `BlegOperation`/outbox) lands inside existing A1 operations or IVR-local state; the no-A1-refinement claim was tested against the OpenAPI and holds.
- **Architecture boundary**: IVR owns media/line facts; backend owns task/entitlement/evidence facts; plan L408 keeps task terminal updates inside the ivr-owner local transaction (A0 owner matrix L275 lists `ivr.outbound_call_task` under `ivr_owner`) and settlement via the entitlement-owner MANDATORY collaborator — no cross-owner DML.
- **Optimal path / overcoupling**: single canonical `docs/16` + one machine model + one zero-dependency validator is the minimum coherent delivery; five prior A1-style custom checks are reused rather than rebuilt; no second truth source, no generic event-relay product.
