## Residual Risk

- **Unlocked advisory semantics.** The listing is an advisory metadata projection, not an authorization lease: the lifecycle recheck and the grant SELECT are separate statements under `READ COMMITTED`, so a lifecycle commit that lands between them can leave that in-flight page stale, and no cross-page snapshot or lease exists (`JooqShareQueryRepository.java:47-63,76`; `plan §5`). Tests deliberately prove visibility, not serialization. Owner: Backend/API.
- **Nesting needs a second pool connection.** Because the template is `REQUIRES_NEW` and pool sizing is deliberately unselected (`plan §5`, `SharingPersistenceConfiguration.java:29-34` uses Hikari defaults), each call made inside an embedding transaction consumes two connections; under nesting plus pool exhaustion, callers would block until the default connection timeout and then receive sanitized `SERVICE_UNAVAILABLE`. No production pool/timeout policy is set by this slice. Owner: Backend/Platform Reliability (Q17/Q23 provisioning boundary).
- **Production collation and cost.** Ordering/tie-breaking is only proven against a fixture created with `--lc-collate=C --lc-ctype=C`; no creator/order covering index exists, and limit+1 bounds returned rows, not scan or sort cost. No `COLLATE` override or index was introduced. Owner: Backend/Database/Platform Reliability.
- **Downstream egress is unproven.** Secret-freeness is proved at this in-process boundary and in captured local logs only; a future edge, serializer or log collector is outside PA10 (`R-A3-REDACTION-RUNTIME` remains the destination). Startup-time pool failures are also outside the per-invocation diagnostic allowlist, so a future operator-facing surface should re-check them. Owner: Security/Observability/API.
- **Trusted-context and cursor boundaries stay open.** `TrustedShareCaller` is constructible by any in-process code and null-tolerant by design (refused `INTERNAL` at the service), and the internal cursor is typed state, not the Q15 opaque wire encoding; authentication, HTTP mapping and cursor signing/512-character policy remain unimplemented by design. Owner: Identity/Backend/Security, Backend/API.
- **Evidence provenance.** The author's `backend/target/pa10-evidence/*` manifests are gitignored and were absent in this review workspace, so their recorded per-file hashes could not be re-verified as delivered; the rebuilt fat JAR is not byte-reproducible (`jar-index.txt` and `pa10-runtime-dependencies.txt` reproduced exactly at the claimed hashes `129480f2…`/`9af85de2…`, while this review's rebuilt JAR hashes `d6cf2509…`). This review therefore relies on its own re-executed inventories, not on archived claims. Remote CI was not dispatched and no exact-head remote run is claimed. Owner: controller acceptance.
