- **Impact:** Valid client input can produce an unclassified 500, a different persisted expiry, a fingerprint/response mismatch or an impossible exact round-trip assertion.
- **Fix criteria:** Freeze one precision policy before comparison/fingerprinting: reject more than six fractional-second digits as 422, or explicitly normalize to microseconds with a stated rule.
