### AG-01-已修复-[低]-业务号码标签否认同一号码已有的登录身份

- **入口/函数**: 小程序“我的 → 账号与登录身份” → `accountSecurityHtml()`。

- **建议改法和验证点**: 业务号码行标识改为“业务用途”，保留不自动授予登录资格的说明；QA 同时确认登录身份、业务用途与非自动新增规则，无矛盾标签，并复查三个尺寸的截图。
