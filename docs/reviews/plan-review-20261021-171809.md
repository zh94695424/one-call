## Assumptions tested / adversarial pass

- Goal-bound minimal design：只新增专项规格和必要跨文档引用；一个行为完整 slice，不把“写设计”扩成 IVR 重建或前端实现。
- Boundary / ownership：现有自研 IVR 拥有通话事实与原始媒体；后台拥有任务、权限、权益和证据验证；可选 FreeSWITCH 不进入强制依赖。
- Concurrency / recovery：单号码唯一性必须跨账户/空间；更换/领取共用锁；callId 重试不能领取新任务；未知通话不能因 30 秒或租约超时被释放。
- TTL：数据库时间检查与领取在同一事务；失效标记扫描不是安全边界；配置快照不追溯更改旧任务。
- Entitlements：resolve 的剩余秒数只是快照，不构成外呼授权；确认后原子预占复用既有计量模型。
- Best-practice / optimal / overengineering：PostgreSQL 索引和短事务足以描述首期热路径；不引入 Redis 队列、独立数据库或重建声讯平台。
- Validation：正常、边界、替换竞争、重复呼入、断网、上传重试和直接未实名试用均进入设计验收；明确无生产测试结论。
