## 6. Lenses applied (summary)

- **Goal-bound minimal design:** single composed slice S1 matches Control's over-design boundary; no future-slice (COS, KMS, public origin, production verifier) folded in.
- **Architecture boundary:** no new Modulith edge; named interface reuse; filter in sharing web layer; evidence byte API behind `evidence::media-read`.
- **Best-practice / optimal:** terminal filter over MVC controller is the minimal change given closed-world customer filter and buffered response; standalone OpenAPI avoids polluting five-surface contract-rules config.
- **Overengineering:** parser is single-range-only (not RFC 7233 multi-range); no generic streaming framework; `ObjectProvider.stream().limit(2)` mirrors existing `MediaPlaybackConfiguration.resolve` pattern rather than inventing new DI machinery.
- **Overcoupling:** PA19 service untouched; gateway is an adapter over the existing authorize/open API; tests extend existing fixtures instead of forking a parallel harness.
