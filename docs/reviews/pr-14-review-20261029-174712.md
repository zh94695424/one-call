## Open Questions

- **OQ-1 — fresh-subject source-event collision mapping:** if a new subject presents an event identity already bound to another subject, the function reaches the insert and PostgreSQL raises native `23505` `uq_trial_grant_source`; only the existing-trial path maps cross-subject reuse to `TRIAL_DATA_INTEGRITY`. This is consistent with the plan's “constraint failures not mapped retain native SQLSTATE” rule and was characterized as an allowed race loser in prior evidence, but the application service must map the native unique error to a stable product outcome. Owner: entitlement-metering service; destination: application-service wave.
- **OQ-2 — session timezone / DST for `valid_days`:** V006:270 computes `v_expires_at := v_granted_at + (valid_days * interval '1 day')`, and V006:303-305 formats UTC tokens, but the function does not set a session `TimeZone`. PostgreSQL calendar-day addition is session-timezone-dependent; in a non-UTC session a DST transition could shift the expiry instant by an hour relative to UTC `plusDays`. CI PostgreSQL 16.15 is UTC and the test asserts `plusDays(7)`. Owner: platform/entitlement owner; destination: deployment timezone validation or a later explicitly approved migration if the platform cannot guarantee UTC.
- **OQ-3 — late FK against pre-existing V005 data:** `fk_ivr_decision_reservation` is added as an immediate, validated `ALTER TABLE` (V006:769-772). Any pre-V006 `ivr_decision.reservation_id` value not present in the new `usage_reservation` table would fail the migration. V005 is a database-only slice with no application service and its fixtures roll back, so no current committed writer is evidenced; the migration fails closed rather than corrupting. Owner: Platform/DBA; destination: production provisioning/backfill gate.
- **OQ-4 — controller log creation-time head:** the controller row records the PR creation head `bd7f84f...`, while GitHub now reports final head `3a08e61...` (the controller-only PR-facts record commit). GitHub metadata is authoritative for this review; owner: controller; destination: bookkeeping only.
