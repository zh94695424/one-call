| Field | Value |
| --- | --- |
| Prior disposition | Accepted in substance (controller); fix required exact registered-ID prefix ownership constrained by `config.sliceOrder`, not the current stage |
| Final status | **已修复** |

Verification:

1. The hardcoded caller is gone. `protocol/ivr/validate.mjs:1943` is now `validateFixture(entry.fixture, expectedSliceForFixture(entry.fixture?.id, config), counters, issues)`. Grep of the fixture loop finds no `validateFixture(entry.fixture, 's1', …)` form.
2. Ownership is derived per exact registered fixture ID. `expectedSliceForFixture` (`validate.mjs:1201-1214`) returns `null` for non-string IDs, IDs without a `-` separator (including empty/leading-dash forms), prefixes outside `config.sliceOrder`, and IDs not exactly present in `config.fixtureIds`. Otherwise it returns the ID’s own prefix — never `args.stage` or another single shared stage token.
3. Cumulative stage semantics are correct by static trace of `STAGE_CONFIG`:
   - `s1` (`sliceOrder: ['s1']`, six `s1-*` fixtureIds) → every current fixture resolves to `s1`.
   - `s2` (`sliceOrder: ['s1','s2']`, six `s1-*` plus eleven `s2-*`) → registered `s1-*` resolve to `s1`, `s2-*` to `s2`; a registered `s3-*` is rejected (`null`) because it is not in `s2.fixtureIds` and `s3` is not in `s2.sliceOrder`.
   - `s3` (`sliceOrder: ['s1','s2','s3']`, 6+11+8) → `s1-*`/`s2-*`/`s3-*` each resolve to their own prefix.
4. Fail-closed on unknown IDs and slice disagreement: unknown IDs yield `expectedSlice=null`; `validateFixture` (`validate.mjs:1229`) rejects non-string / empty expected slices; a registered ID whose `fixture.slice` disagrees with the prefix fails `fixture.slice !== expectedSlice`. Duplicate registered IDs are separately flagged (`validate.mjs:1933-1935`).
5. The current stage is not passed as every fixture’s expected slice. The only stage input to the resolver is membership in that stage’s `sliceOrder` and `fixtureIds`; the returned value is the fixture’s own prefix.
6. Hashes of the fixed validator and all six fixtures match the fix artifact and controller record (`validate.mjs` `3a01cbd5…`; fixtures `b3965d58…`, `3628fbcc…`, `cdc45fab…`, `f1d0dc52…`, `e22353ea…`, `7fa69de7…`).
