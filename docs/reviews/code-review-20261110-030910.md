### 1. Bundle parser — strict UTF-8/BOM/schema/duplicate/kid/role/hex/bounds/ordering/redaction

- **Closed schema.** Root is exactly `{schemaVersion, keys}` (`:38`, `:73-77`); `schemaVersion` must be integral, int-convertible and equal to 1 (`:39-40`); `keys` must be a nonempty array (`:41-42`); every entry is exactly `{kid, role, keyHex}` (`:47`, `:73-77`). With exactly N distinct allowed names required, `size == N` plus the allowed-name test proves all required names are present; duplicates are rejected at parse via `STRICT_DUPLICATE_DETECTION` (`:28`). Missing/null/non-text fields fail through `text()` (`:79-82`).
- **Kid/role/hex.** Kid regex is the PA21 `[A-Za-z0-9_-]{1,32}` (`:51`), duplicate kid is rejected by `!kids.add(kid)` (`:51`), roles are the exact enum names via `Role.valueOf` (`:53`), hex is exactly 64 lowercase characters (`:52`), and decoded material must be exactly 32 bytes (`:54-57`). `Entry` construction clones the material and the owned temporary array is cleared (`:58-59`).
- **Exactly one ACTIVE / canonical order.** A second ACTIVE fails (`:60-62`); absence of ACTIVE fails (`:65`); VERIFY_ONLY is ASCII-sorted by kid (`:66`) and returned once through the existing immutable `Result.Available` (`:67`, `MediaPlaybackSigningKeyProvider.java:19-23`).
- **Fail-closed and no leak.** Every failure returns `Result.Unavailable` (`:33,40,42,52,57,61,65,69`); only `CharacterCodingException | RuntimeException` is caught (`:68`), so JVM `Error` is not swallowed; no logging/cause attachment. ### 2. File adapter — boundary, no-follow read, bounds, race/file-key, reread, fail-closed

`FileMediaPlaybackSigningKeyProvider.currentKeys()` (`FileMediaPlaybackSigningKeyProvider.java:22-33`) stores only the configured path string (`:17`) and rereads every call; it does not cache or retain key bytes or a last-good result.

- **Path boundary.** Null/blank fails (`:25`); `Path.of` failure (including NUL) is caught (`:26,30`); non-absolute and non-normalized paths fail (`:27`). `checkedAttributes` walks from the filesystem root and rejects a symlink in any component (including the root and final file) using `NOFOLLOW_LINKS` (`:58-70`).
- **Bounded read-only I/O.** Advertised size must be a nonempty regular file within 65,536 bytes (`:36-38`); the channel is opened with exactly `READ` + `NOFOLLOW_LINKS` (`:42`); a fixed `MAX_SOURCE_BYTES + 1` buffer detects overflow while reading (`:39-47`), and a zero-byte progress read is a failure (`:46`).
- **Short/truncated/oversized/race checks.** After the read, position must be `<= 65,536`, equal the pre-read advertised size, and the re-read attributes must still be regular with identical size, file key and `lastModifiedTime` (`:49-53`). This rejects short reads, growth/shrink, and ordinary final-file replacement between checks; `NOFOLLOW_LINKS` plus per-component checks reject symlink traversal. The plan explicitly does not claim elimination of hostile filesystem races; that remains a residual, not a defect.
- **Fail-closed mapping/redaction.** `IOException | RuntimeException` (including `AccessDeniedException`, `SecurityException`, unsupported no-follow operations, invalid paths) maps to `Result.Unavailable` (`:30-31`); buffers and the returned source copy are zeroed in `finally` (`:32,55`); the parser's returned `Entry` material is an independent clone; `toString`/`@JsonValue` is constant redaction (`:72-73`); no path/content/exception is logged or attached.

Decisive tests: `readsOnlyConfiguredAbsoluteRegularFile`, `rejectsMissingBlankRelativeAndInvalidPaths`, `rejectsMissingDirectoriesAndSymlinkSources` (final-file and parent-component symlinks, with a deterministic mock fallback rather than a skip), `mapsReadPermissionAndIoFailuresToUnavailable`, `rejectsEmptyAndOversizedSourcesBeforeParsing` (zero/65,537/exact-65,536, plus advertised-size-vs-actual short/truncated/same-size replacements), `neverSearchesFallbackLocations`, `rereadsReplacementWithoutCachedFallback`, `removalAndCorruptionImmediatelyFailClosed`, `returnsIndependentImmutableSnapshots`, `redactsPathMaterialAndFailures` (`FileMediaPlaybackSigningKeyProviderTests.java:33-194`).
