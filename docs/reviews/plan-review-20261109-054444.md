Implementation must use `epochSecond × 1,000,000 + getNano() / 1,000` as the canonical microsecond value and reconstruct with `floorDiv`/`floorMod`; the January golden vectors and current production timestamps are positive, so this is an assertion-precision concern, not a redesign blocker.
2. **Golden fixed Clock:** use `Clock.fixed(Instant.ofEpochMicro(1767323045678901), ZoneOffset.UTC)` or another instant within `[notBefore, expiresAt)`; do not verify January vectors against wall time.
3. **REAL fixture context:** add the mode flag inside the allowlisted fixture without weakening the six stub methods, and assert bean-count/identity directly rather than relying on profile or bean-ordering inference.
