## 3. Open questions / implementation-time notes

1. **COPY FROM probe observability.** The plan requires server-side `42501` before COPY input mode and explicitly rejects a driver-unsupported-COPY outcome (line 358). With PGJDBC, the permission error should precede `CopyInResponse`, but this was not executed here. Implementation must prove the actual exception is SQLSTATE `42501`, not a client-side COPY API error; if PGJDBC cannot surface the server error through `Statement.execute`, use a raw connection path that still reaches the server check.
2. **V011 rollback proof of the PUBLIC TEMP revoke.** The appended `SELECT 1/0` copy must run against a cluster whose pre-copy state still has PUBLIC TEMP (a V010-state cluster), otherwise the “pre-migration snapshot” already contains the revoke and the rollback of that specific mutation is not proven. The plan's wording is implementable on the isolated V010 cluster, but the sequence should be explicit in implementation.
3. **§9 lookup-site wording.** §9 attributes “both lookup sites” to the renamed `publicProjectionUsesDedicatedRoleOnSameReadOnlyConnection` method; the actual by-type sites are in `publicProjectionAndDependencyFailuresFailClosedWithoutPartialContent` (`PublicSharesIT.java:185`) and the `service(...)` fallback (`:299`). §6 lines 175 states the correct two sites. Implementation should follow §6 and grep for `getBean(ShareableEvidenceProjectionReader.class)`.
4. **Protected public-source bans are whole-word sensitive.** `PublicSharePersistenceConfiguration.java` is in `PUBLIC_READ_FILES`, and `SharingQueryBoundaryTests` rejects whole words create/update/delete/merge/truncate/alter/drop anywhere in the file. The exact plan code passes; comments or identifiers added during implementation must not introduce them.
5. **Ambient public URL in a command-only context.** The public reader activation is URL-presence only. If an environment/system property leaked `onecall.sharing-public-read.datasource.url` into a command-only context that does by-type lookup, ambiguity would return. No such context exists in this repository/CI; this is a residual, not a current defect.
6. **Control identity drift (observation, not a finding).** The fix artifact records the Control it read as 3,796 lines / SHA-256 `3582098D...`; the frozen Control in this snapshot is 3,798 lines / SHA-256 `0d325c02...`. The PA16 Goal Confirmation text (lines 15–25) is intact and the extra lines are Controller adjudication/intake/re-review material, so this is an expected Controller-owned update, not plan drift.
