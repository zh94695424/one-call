## Open Questions

1. **Typed-matrix qualification.** The fix report correctly notes that an invalid UUID string cannot inhabit the typed `UUID` facts accessors and that `Integer` seconds cannot overflow the production nanosecond multiplication. The matrix therefore exercises the producer/constructor failure for those rows (`UUID.fromString`, `Duration.toNanos`, and constructor validation) rather than an impossible raw-string service input. This is accepted as evidence-consistent and is not treated as a missing production check.
2. **Supplied external evidence.** The authoritative patch, base snapshot, `.review-evidence`, and external `SKILL.md` were outside the read allowlist and were not independently re-hashed or rerun. The frozen V001–V008/OpenAPI/POM checks, the 445-method inventory, and the fix-scope mtime inspection were performed directly on the workspace bytes; the Controller full-suite and XML evidence remain supplied.
3. **Pre-existing concurrent cross-purpose same-request-key race.** The event identity includes `eventType` while prior lookup is by request-key digest; two concurrent first calls with the same request key and different purposes can create distinct success events. This is unchanged by the fix and remains a Sharing/Backend residual, not a PA21 regression.
4. **Authority replay caller trust.** `issueOrReplay` accepts the caller-supplied committed expiry/anchor within the current bound; the production service validates the committed event before passing it. Confirm the authority remains intentionally usable only behind that service contract.
