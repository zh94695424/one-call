### C1-已修复-中-授权过期后的 B 路启动边界（re-review accepted）

- **入口/函数**: `POST /api/v1/ivr/inbound/resolve` returns `DIAL_TASK_CALLEE`; IVR resumes or initiates the unique B-leg operation.
- **文件(行号)**: `docs/13-ivr-call-task-and-inbound-design.md:202`, `:247`, `:251`.
- **输入场景**: IVR is delayed or retries after `authorizationExpiresAt`, with no line request previously issued.
- **实际分支**: the design prohibits a new line request at or after the deadline. IVR may report `OUTBOUND_NOT_STARTED / AUTHORIZATION_EXPIRED` only when its durable operation record proves no line request was issued; uncertain line outcomes require reconciliation.
- **预期行为**: expired authorization cannot initiate stale external dialing; only an authoritative no-outbound terminal fact can fail the task and release its reservation.
- **直接证据**: the event is correlated by `callId + eventId`, includes the original `reservationId`, and settles task failure plus reservation release in one backend transaction only after no accepted outbound/answer/bridge fact exists. Conflicting late line facts are isolated, not used to reopen the task or debit twice.
- **影响**: prevents delayed retries from placing an unauthorized call or releasing reserved entitlement while the line outcome is unknown.
- **建议改法和验证点**: fixed in the design. The later runtime slice must test expiry before first line request, request issued before expiry but answered after expiry, and ambiguous request outcome; no code/runtime behavior is claimed here.
- **修复风险（低/中/高）**: 低。
