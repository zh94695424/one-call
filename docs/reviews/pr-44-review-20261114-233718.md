Verification: extend `missingCredentialsAndCursorKeysFailAtAffectedRequestNotBoot` and `startupPropertiesProvidersAndPoolFailuresAreRedacted` (existing fixed identities; the gate forbids new ones) with `keys[1]`-only, `keys[3]`, `keys[0].id` without `material`, `keys[0].comment`, userinfo-bearing URL; re-run `OperationsSubjectReadConfigurationTests`, `OperationsSubjectReadWebTests` and both read ITs.
