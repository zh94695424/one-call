## Adversarial semantic pass

- Privilege path: `PROPAGATION_REQUIRES_NEW` + `readOnly=true` + `READ_COMMITTED`, first statement the fixed literal `SET LOCAL ROLE sharing_role`, then a `current_user` assertion, then lifecycle reads, then the grant SELECT — all on one checkout because jOOQ’s provider wraps `TransactionAwareDataSourceProxy` over the same pool. Confirmed by captured execution facts (single checkout, effective role `sharing_role`, `transaction_read_only=on`, isolation, stable backend PID) rather than by configuration inspection. `SET LOCAL` reverts at commit/rollback and `assertCleanPool` proves the returned connection is role-clean.
- Scope: creator predicate is unconditional; personal is `owner_organization_id IS NULL`, organization is exact equality; no OR-widening, no owner shortcut, no role matrix (all four membership roles behave identically), no status/time filter (all stored statuses are advisory-listed, per README). Cursor must echo the caller’s account and organization or it is rejected **before** any statement (verified with an empty execution capture).
- Keyset: strict `valid_from < anchor OR (= anchor AND share_id < anchorId)` under `ORDER BY valid_from DESC, share_id DESC`, i.e. exactly the frozen `x-onecall-sort`; comparator is database-native (no `COLLATE`, no Java comparator), microsecond anchors are preserved and sub-microsecond values are rejected instead of rounded; UTC-bound `OffsetDateTime` binds make traversal zone-independent. Traversal is additionally guarded against non-termination and duplicate/gap replay across concurrent inserts.
- Projection: 11 columns, order and types identical to the frozen `ShareSummary` schema (required set, `minLength 1`/`maxLength 128`, `minimum` bounds, nullable `maxAdmissions`, both closed enums in frozen order) and to the V009 checks the record invariants mirror; `content_snapshot`, hashes, salt, capability token, object key/version and permanent URL are never selected. The read of `customer_iam`/`organization_access` uses exactly the columns V009 grants to `sharing_role` (line 338-351), so no privilege is stretched.
- Failure handling: every `RuntimeException` path rolls back, emits exactly one sanitized six-field `ShareQueryDiagnostic` (validated 5-character SQLSTATE or absent, 2-character class or `NON_SQL`, exception class name only, role-assertion boolean), rethrows a closed `ShareQueryException` with constant text and no cause. Logback captures in both unit and container layers prove no SQL, bind, identity, credential, row or stack text escapes; poisoned enum mapping fails `INTERNAL` with no partial page.
- Injection/surface: indexed prepared binds only, `DSL.name(...)` identifiers, caller input never forms SQL, `executeLogging(false)`, jOOQ/Hikari loggers muted in the profile file, no product listener, `internal` package with no public module API, default profile creates zero persistence beans (asserted by type, not only by bean name).
