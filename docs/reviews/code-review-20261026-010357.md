## 2. Open Questions

1. **masked 豁免的契约解释权**：plan/doc 只说 “masked 变体（如 `calleeNumberMasked`）允许”，未枚举允许集，也未说明 `*Masked` 键是否必须应用 pattern controls。本评审按 INV-A3-15 分层管道与 `failurePolicy` 的 unknown-field block 判定通配豁免为越界；若 controller 裁决 “任何 Masked 后缀即为可信 display 字段” 为契约本意，则需回改 doc/model 显式写明该信任边界，否则 evaluator 与文本的张力仍在。修复前应由 controller 定夺窄化（派生变体）与 pattern 叠加二选一或组合。
2. **运行期注入探针未实跑**：本会话权限门对 `node`/`npm`/`python3` 一律返回 `This command requires approval`（`node --version` 可用，`v22.23.4`）。F-S3-R1-01/02 的分支推演为静态 JS 语义结论；controller 复验时应在 `/tmp` 副本注入 `capabilityTokenMasked: "Bearer …"` 与省略 method 的 USE 各一次确认实际输出。
3. **修复是否授权改 fixture**：任务规定评审期不得改 fixture；F-S3-R1-01 建议的 `*Masked` credential 负例与 F-S3-R1-02 的缺省 method 负例若要固化进 `sec-s3-06`/`sec-s3-01`，需 controller 在 fix 授权中明确（或仅以临时探针留证、fixture 不动）。
4. **playback PRESENT 不复核 `sessionExpiresAt`**：ISSUE 已强制 `expiresAt ≤ sessionExpiresAt`（`security/validate.mjs` playback ISSUE 段），PRESENT 只查 credential `expiresAt`；在“凭证寿命被 session 封顶”前提下无独立缺口，但若未来允许独立延长 credential TTL 需重审。归入既有 `R-A3-MEDIA-*` 残留语境，不单列 finding。
