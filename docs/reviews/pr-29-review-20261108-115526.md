2. **CONNECT baseline / least privilege (owner: Database/Platform/Security).** The role's connection privilege comes from the PUBLIC baseline; an explicit reader CONNECT is rejected. A future hardened deployment that revokes PUBLIC CONNECT needs an explicit contract/migration decision.
3. **No row-level scoping (owner: later PA19 authorization).** Any holder of the role can read the 15 columns for all evidence rows; the reader API has no tenant/subject parameter. PA19 must authorize before calling; this is the accepted model, not a row-isolation claim.

7. **Multi-database `pg_shdepend` assumption (owner: Database/Platform).** V013's dependency set is current-database-scoped while `granted` detection has no `dbid` filter; the project already assumes one database per cluster.
