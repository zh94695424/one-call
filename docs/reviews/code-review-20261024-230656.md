## Open Questions

1. **Registry reverse membership.** `validateRegistrySurfaceBacking` enforces registry→operation only. An operation may declare a code whose registry `surfaces` list omits that operation’s surface without failing the new rule (the code still must exist in the registry). No current violation was found. Optional future hardening; not required by the F-07 adjudication and not elevated as a finding.
2. **AuditFact cross-field null rules.** A0 requires `actor_id` non-null unless `actor_type = SYSTEM` and `object_id` non-null unless `object_type = SYSTEM`. The contract records these rules in descriptions (`onecall-v1.openapi.yaml:5972,5988`) but does not encode them as response-schema conditionals. Acceptable for the static A1 goal; response-side `if`/`then` was out of the adjudicated request-keyword ban scope.
3. **Global T-S/uq/ck ownership.** Unchanged classified API-governance residual: `a0ContractAnchors()` still accepts any `T-S[123]-NN` / `uq_` / `ck_` token found in docs/14.
