- **直接证据**:
  1. Framework version: `backend/pom.xml:11` — parent `spring-boot-starter-parent` `4.1.2`.
  2. The property is **removed**, not merely renamed-with-alias: `META-INF/spring-configuration-metadata.json` inside `spring-boot-web-server-4.1.2.jar` declares `server.error.path` (default `/error`) with `deprecation = {level: error, replacement: spring.web.error.path, since: 4.0.0}`.
