- **签票窗口 micro-race（B-F-05 同类，deferred 不重开）**：`ticketContext:275-277` 复查通过后，`issue:285-287` 再取 `now` 并与 expiry 比较；此窗口内过期会走 `ticketFailed`（`TICKET_FAILED` 事件 + 410），而非 A F-PA17-01 的零事件 410。窗口已从"整个 policy/proof 期间"缩到"复查后到签票前"，且 `ticketFailed` 为 fail-closed；仍留有事件面差异
- **observation 失败映射**：`observation` 独立事务若抛错，`admit` 走 `catch → 503 DEPENDENCY_UNAVAILABLE`（fail-closed，admission 已提交）。相比旧行为（嵌套在 denial 事务内），客户端可见状态由"已拒绝"变为"503"，audit 事实等价（observation 行未写入时无伪造记录），但调用方重试语义略有变化
- **测试缺口**：(a) typed validation → `DeniedCommitted(VALIDATION_FAILED)` 仅有 binder 层覆盖，无服务层专用单测；(b) personal-owner/畸形 identity 的容器级 IT 未覆盖（`PublicShareAdmissionIT` fixture 固定为 org-owned grant，个人路径仅单测）；(c) `ticketContext` 死 facts（finding 1）若不修，无回归测试能察觉
