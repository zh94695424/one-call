- **反例/失败场景**: A publication with an old ACTIVE retires the old row and activates the candidate; a naive projection reuses the pre-transition locked current ACTIVE ID (the old version) instead of the candidate. - **直接证据**: `api/openapi/onecall-v1.openapi.yaml:5741-5779`; plan §6.2 line 209; §7.2 O5 line 242 and P8 line 230; §9.1 `returnsExactCatalogVersionState` (`:307`) and `successHasExactStateAndHeaders` (`:311`); no occurrence of `currentActiveVersionId` in the plan's SQL/projection bullets.
- **影响**: Wrong public response field for publication-with-retirement and offsale replay; review cannot accept the exact response contract; test gaps.
- **建议改法和验证点**: Define the field explicitly: for publication and publication replay, the post-transition/locked current ACTIVE (the candidate); for real offsale, `null` (the unique index leaves no ACTIVE); for offsale replay of an already-OFFSALE target, the locked reread's current ACTIVE ID or null.
