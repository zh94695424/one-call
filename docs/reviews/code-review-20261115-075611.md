## Residual Risk

- **Keyset 无支撑索引**：全局 `ORDER BY occurred_at DESC, id DESC LIMIT n+1`（`JooqOperationsActivationHistoryReader.java:39,48`）没有任何匹配索引——`V007:161-162` 只有 `(subject_id, occurred_at DESC)`。每页都需要对全表做 top-N 排序扫描；配合 `OperationsReadContext.java:38` 的 `SET LOCAL statement_timeout='2000ms'`，数据增长会把该端点整体推入 sanitized 503。Control 已把它作为接受的遗留风险交给 Backend/Database（无 V018 授权），故不作为 finding。
