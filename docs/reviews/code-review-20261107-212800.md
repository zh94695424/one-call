### LR-01 — Low (test robustness): HTTP `expiresAt` string compared against six-digit canonical witness text

- **Entry/function:** `PublicShareAdmissionIT.responseAndAccessPayloadRedactAllForbiddenMediaFacts` asserting the 200 response body.
- **File (lines):** `backend/src/test/java/com/onecall/archtests/container/PublicShareAdmissionIT.java:1025-1032`; comparison helper `mediaBoundText` at `:1178-1181`; PA17 canonical formatter `DefaultShareAdmissionService.java:345`.
- **Input scenario:** any successful media authorization whose durable witness bound has a nonzero nanosecond value that is an exact multiple of 1,000,000 (i.e. a whole-millisecond partition of the PostgreSQL microsecond timestamp).
- **Actual branch:** `assertThat(body.path("expiresAt").asString()).isEqualTo(mediaBoundText(witness.payload()))` — the witness text is produced by `appendInstant(6)` (six fractional digits whenever nanos != 0), while the HTTP body `Instant` is serialized by the Spring/Jackson ISO instant serializer, which prints 3, 6 or 9 fractional digits as needed.
- **Expected behavior:** compare instants, not their textual renderings; the two-connection test in the same file already does this correctly at `:879` (`isEqualTo(Instant.parse(bound))`).
- **Actual behavior:** for a whole-millisecond bound the witness string is e.g. `...123000Z` while the JSON body renders `...123Z`; the assertion fails even though the credential/expiry are correct.
- **Direct evidence:** `:1032` string comparison vs `:879` instant comparison; `:1178-1181` returns the witness payload string; `:896`/`:910` compare via `Instant.parse`.
- **Impact:** intermittent false failure (~1/1000 of runs for that timestamp shape) in a 295-test container-smoke suite — no false pass and no product defect, but it can force reruns and obscure real failures.
- **Suggested fix / verification:** parse both sides to `Instant` (mirror `:879`) or compare the response expiry to `Instant.parse(mediaBoundText(...))`; keep the payload/hash assertions unchanged.
- **Fix risk:** Low (single test assertion).
- **Severity:** Low.
