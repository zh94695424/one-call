### Accepted B Finding 1 — 已修复 (fixed; not open)

- **入口/函数**: `v007OwnerPublicRuntimeAndCrossModuleAclsAreExact` → `assertV007SchemaUsageMatrix`.
- **文件(行号)**: `backend/src/test/java/com/onecall/archtests/container/PostgresContainerIT.java:8431-8468` (new `operations_iam` table/column zero-ACL block); helpers at `:18128-18136`; schema-level denial at `:8424-8427`. V007 SQL grants no `operations_iam` schema/table/column privilege (`V007__activation_and_consent.sql:201-256`).
- **输入场景**: final database contains live `operations_iam` base tables/columns; a stray `GRANT` of SELECT/INSERT/UPDATE/DELETE/TRUNCATE/REFERENCES/TRIGGER (table) or SELECT/INSERT/UPDATE/REFERENCES (column) to `activation_consent_role` exists despite that role having no `operations_iam` schema `USAGE`.
- **实际分支**: the block enumerates every live `information_schema.tables` BASE TABLE in `operations_iam` (non-empty assertion) and every actual column per table (non-empty assertion), then calls role-explicit `has_table_privilege(role, 'schema.table', privilege)` / `has_column_privilege(role, table, column, privilege)` and asserts false for all listed privileges.
- **预期行为**: `activation_consent_role` has zero `operations_iam` table/column ACL entries; schema `USAGE` denial alone is not treated as proof.
- **实际行为**: a leaked table grant would return `true` and fail `.isFalse()`; a leaked column grant would likewise fail. The check is executable and fail-closed.
- **直接证据**: `hasTable`/`hasColumn` pass the role as the first argument and the schema-qualified relation name (`:18128-18136`). PostgreSQL `has_table_privilege`/`has_column_privilege` examine the object ACL for the supplied role and do not require that role to hold schema `USAGE`; the query runs on the migration-identity/superuser connection, so name resolution is not blocked by the role’s schema denial. The non-empty asserts prevent a vacuous empty loop.
- **影响**: closes the accepted proof gap (latent grant would otherwise be invisible); no production code, SQL, grant or policy was changed by the fix.
- **建议改法和验证点**: none required for this finding. Optional future mutation proof (create a stray grant in an isolated copy, observe failure, revoke) would strengthen the dynamic demonstration; not a current requirement.
- **修复风险（低/中/高）**: 低 — test-only.
- **严重程度（低/中/高/严重）**: 低（proof-only, now fixed）.
