### F1-[High]-Serializer-fault evidence is absent and the required target is `CustomerSharePage.Item`, not `ShareSummary`

- **实际行为**: the buffering code in `CustomerBoundaryFilter.java:74-83,86-127` appears structurally capable of discarding partial output, but nothing triggers or proves it. - **建议改法和验证点**: add the dedicated nested test configuration and context inside the existing method, install the throwing serializer for `CustomerSharePage.Item` only, assert status 500, `application/problem+json`, exactly `type,title,status,code,traceId`, no sentinel/exception text, no partial JSON, and independent context close; verify the fault module is not active in the main wire context.
