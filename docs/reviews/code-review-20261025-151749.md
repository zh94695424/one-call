### Finding 1 — `localBlegDispatch` skips the authorization-expiry guard when `now` is omitted or non-string

| Field | Value |
| --- | --- |
| Severity | **Low** |
| Entry/function | `ProtocolMachine.localBlegDispatch` |
| File/line | `protocol/ivr/validate.mjs:1852-1866` (guard at 1861–1862) |
| Model/spec counterpart | Model transition `PREPARED→DISPATCHING` guard `"persisted marker; now before authorizationExpiresAt; lineAttemptCount 0"` (`ivr-protocol-v1.json` ~1719–1722); spec §6.5 table row `PREPARED → DISPATCHING` (`docs/16…md:291`) |
| Triggering input | `handleLocal('bleg.dispatch', callId, { callId })` with **no** `now` (or a non-string `now`) on a call whose B-leg is `PREPARED` with `lineAttemptCount=0` and a past `authorizationExpiresAt` |
| Actual branch | `typeof body.now === 'string' && body.now >= call.bleg.authorizationExpiresAt` is false because the left operand is false → guard skipped → `phase='DISPATCHING'`, marker written, status 200 |
| Expected behavior | Fail closed with `409 AUTHORIZATION_EXPIRED` (same as the string-`now` past-deadline path), or require `now` as a mandatory typed field of the local dispatch body |
| Actual behavior | Dispatch succeeds after authorization expiry if the caller omits `now` |
| Direct evidence | Lines 1861–1862: `if (typeof body.now === 'string' && body.now >= call.bleg.authorizationExpiresAt) { return { status: 409, code: 'AUTHORIZATION_EXPIRED' }; }`. Contrast `localBlegExpire` (1937–1938) which fails closed when `now` is not a string (`typeof body.now !== 'string'` → `AUTHORIZATION_NOT_EXPIRED`). All current S2 dispatch steps that need the deadline check pass a string `now` (e.g. `s2-01` `dispatch` body `now: "2026-10-25T10:00:10Z"`), so no shipped fixture exercises the fail-open path |
| Impact | The fixture evaluator does not enforce the frozen `now < authorizationExpiresAt` guard as a fail-closed local contract. A future fixture (or a mutated probe) that omits `now` and expects post-deadline dispatch to fail would silently pass dispatch instead. Does not affect production backend code (this is evaluator-only) and does not invalidate any of the 11 current fixtures |
| Fix direction | In `localBlegDispatch`, treat missing/non-string `now` as either (a) always-expired fail-closed (`409 AUTHORIZATION_EXPIRED`) or (b) a typed required field rejected with `409`/`422` before the phase change. Prefer mirroring `localBlegExpire`'s fail-closed polarity. Verification: add a temporary probe fixture (or controller mutation) that dispatches with past `authorizationExpiresAt` and no `now`, assert `409 AUTHORIZATION_EXPIRED` and `phase` still `PREPARED`; re-run `node protocol/ivr/validate.mjs --stage s2 …` and expect the unmutated suite still `passed=17` |
| Fix risk | Low. Tightening the guard cannot make a currently-passing fixture fail, because every current dispatch step that relies on the deadline supplies a string `now` that is before expiry. Only an intentional omit-`now` probe would need updating |
| Adjudicable? | Yes — one-line predicate change with an explicit fixture/probe |
