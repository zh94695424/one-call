### 1-未修复-低-B-5 闭环过度声明：§3.3 未穷尽冻结函数 P0001 token 且误归因 INCOMPLETE
- **位置**: §3.3 映射表（plan :81-96）与 §10.3 B-5 行（plan :514）
- **问题类型**: 契约缺失 / 不可直接实施
- **当前写法**: 表头声明 “exact existing public outcomes”，只列 `IDEMPOTENCY_INCOMPLETE from begin/complete`、`IDEMPOTENCY_ARGUMENT_INVALID`、`OUTBOX_PAYLOAD_INVALID`、`OUTBOX_DEDUPE_CONFLICT` 四个 token；其余依赖 “Unknown tokens/constraints/errors default to sanitized 500 INTERNAL”。§10.3 声称 “§3.3 exact existing platform-token … mappings”。

- **为什么有问题**: Controller 接受 B-5 的原意正是要求对冻结函数 token 给出显式公开结果映射；plan 声称“exact/穷尽”但实际覆盖 4/8，且 `IDEMPOTENCY_INCOMPLETE` 只由 `idempotency_begin` 抛出、`idempotency_complete` 从不抛出，归因 “from begin/complete” 与冻结实现不符，属于不成立的闭环声明。

- **影响**: 实施返工 / 可能生成错误 public code 映射 / review 难以验收（闭环表与代码事实不符）
