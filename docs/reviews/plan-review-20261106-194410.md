## 4. RR5 关闭明细

### RR5-01 — member witness recipient binding — VERIFIED CLOSED

- §9A L376 冻结：`ORGANIZATION_MEMBER` 在 §2.2、§2.3 两个 final-recheck 分支与 §2.4 reconstruction 上要求：
  - trusted current account ID = witness `recipientAccountId`；

### Ticket-window / grant-terminal mapping — VERIFIED CLOSED

- §9A L378：commit 后 `ticketExpiresAt - clock_timestamp() <= 0` → 恰一条 `TICKET_FAILED`/`TICKET_WINDOW_EXPIRED` + 返回 **410 `SHARE_SESSION_EXPIRED`**；不 recount、不回滚。
