### F-PA5-PR-01-未修复-高-`ix_call_record_subject_time` 冻结索引与 22 列字典矛盾，必须用户/schema 权威裁决
- **位置**: plan §4.3 item 2, §4.4 ordinary index list, §9 F-PA5-PLAN-01, §13; frozen `docs/14` §4.25 keys/indexes line 1445 vs the 22-column dictionary and §13.2.1
- **问题类型**: 契约缺失 / open question 未收敛 / 不可直接实施
- **当前写法**: Frozen text is `Index ix_call_record_subject_time (subject_id, ended_at, created_at)`. `call_record` has no `created_at` in the frozen 22-column dictionary, the §4.1 catalog row, or §13.2.1. The plan recommends `CREATE INDEX ix_call_record_subject_time ON ivr.call_record (subject_id, ended_at);` and calls it a required executable resolution pending review.
- **反例/失败场景**: An implementation agent that follows the frozen literal cannot create the index. An implementation agent that follows the plan's two-column form creates an index whose `indexdef` permanently diverges from `docs/14` line 1445. A later query designed as `WHERE subject_id = ? ORDER BY ended_at DESC, created_at DESC` loses its tertiary sort key: all live `ACTIVE`/`UNKNOWN` rows have `ended_at IS NULL`, and ties on `ended_at` (including the entire live-call set) become unordered. A future wave that trusts the frozen three-column name will assume a contract that V005 did not create.
- **为什么有问题**: No normative section uniquely resolves the intended shape. §4.25 freezes both the 22-column set and the three-column index; §4.1 and §13.2.1 independently confirm 22 columns and no `created_at`; docs/12 Phase B and §9.x specify no query that would authorize a drop or substitution. This is therefore not an executable transcription correction: every candidate changes a frozen contract (index shape or column count).
- **直接证据**:
  - `docs/14:1445` — `Index ix_call_record_subject_time (subject_id, ended_at, created_at).`
  - `docs/14:1395-1418` — 22-column `call_record` dictionary; no `created_at`.
  - `docs/14:381` — §4.1 catalog field-6 column list; no `created_at`.
  - `docs/14:4443-4444` — §13.2.1 `need["ivr.call_record"]=22`.
  - Repo-wide search: the three-column form appears only at `docs/14:1445`; no query or errata resolves it.
  - Contrast: `ix_inbound_session_subject_time (subject_id, created_at DESC)` uses a real column; `ix_call_record_subject_time` is the only index naming a non-existent column.
- **影响**: Implementation cannot start; wrong resolution silently changes an accepted index contract or the frozen 102-column total; test `indexdef` freeze would then lock in the unauthorized shape; later call-history ordering/replay assumptions may fail subtly.
- **建议改法和验证点**:
  1. Stop before S1. Do not author V005 until authority chooses one of:
     - **A. Two-column substitution** `(subject_id, ended_at)` — preserves name, index count, and all frozen table/column/check totals; changes only the index shape; must be recorded as an authorized errata of `docs/14` §4.25 line 1445 (S1 artifact + PA5 control gate record), not as a silent transcription.
     - **B. Add `created_at` to `call_record`** — preserves the literal three-column index; changes the frozen column total 102→103 and §13.2.1/§4.1/§4.25; requires a design-source amendment.
     - **C. Substitute `started_at`** — still a guess; `started_at` is nullable and is semantically call-start, not creation; does not uniquely resolve the frozen text.
     - **D. Amend the design source first** and keep PA5 stopped until `docs/14` is corrected.
  2. If A is chosen, the S1 `indexdef` freeze must match the authorized two-column text exactly, and the plan/§4.3 must stop calling it a semantics-preserving transcription (see F-PA5-PR-02).
  3. If B is chosen, update column totals, §13.2.1 expected count and all dependent inventory assertions before implementation.
- **修复风险（低/中/高）**: 中 — A is a one-line DDL choice but requires explicit authority and durable errata; B/D touch the frozen design source.
- **严重程度（低/中/高/严重）**: 高 — blocking for S1.

**Exact minimal decision required from user/schema authority:** choose resolution A, B, C or D for `ix_call_record_subject_time`. Implementation must stop because no existing normative source uniquely resolves the contradiction, and the plan's recommended two-column form changes the accepted index contract rather than transcribing it.
