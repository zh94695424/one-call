## 4. Open Questions

1. **Password handoff format and timing** (external input): the plan defers all password setting to a Platform/Database/Security handoff after step-2 Flyway and before post-handoff check. The exact handoff channel/artifact format is not specified inside the snapshot and cannot be verified here — confirm at implementation-gate intake that a concrete, nonsecret-variable-compatible procedure exists.
2. **Superuser availability for step 1**: apply requires a superuser provisioning identity (role creation/attribute changes). Confirm the production execution identity and its custody path are assigned (Q17/Q23 → Platform/Database/Security) before the runbook is exercised.
3. **Test container network auth**: the `28P01` wrong-password tests depend on host JDBC/TCP password authentication being available for the `postgres:16` fixture (default `POSTGRES_PASSWORD` behavior; no `POSTGRES_HOST_AUTH_METHOD` override in the fixture). Confirm the PA25 test harness does not weaken container auth to achieve those assertions.
