## Findings

### F-01-未修复-中-procedure ACL reset invokes FUNCTION syntax for procedures

- **入口/函数**: Flyway V010 ACL-reset `DO $reset_acl$` block, specifically the `pg_proc` loop.
- **文件(行号)**: `backend/src/main/resources/db/migration/V010__sharing_role_least_privilege.sql:83`
- **输入场景**: Any procedure exists in one of the nine bounded schemas when V010 is replayed, for example `CREATE PROCEDURE probe.p() LANGUAGE plpgsql AS $$ BEGIN NULL; END $$`, even when no ACL was explicitly seeded.
- **实际分支**: The query selects every `pg_proc` row whose namespace is one of the nine bounded schemas and does not filter `prokind` or distinguish `FUNCTION` from `PROCEDURE`; the loop then executes `REVOKE ALL PRIVILEGES ON FUNCTION ...` for that row at line 88.
- **预期行为**: V010 must reset procedure ACLs across all nine bounded schemas and then enforce the exact procedure/routine postcondition without aborting merely because a routine is a procedure.
- **实际行为**: PostgreSQL 16 rejects the statement with `ERROR: probe.p() is not a function` (disposable-container probe exited 3). The migration transaction aborts before the reset and postcondition phases. This fails closed, but it does not perform the required procedure reset and makes V010 inapplicable whenever a bounded-schema procedure exists.
- **直接证据**: The bounded schema loop is at `V010...sql:62`; the unfiltered `pg_proc` scan is at `:83-86`; the incompatible `ON FUNCTION` statement is at `:88`. V001-V009 define no procedures, so the current clean replay and XML cannot exercise this branch. The PostgreSQL 16 probe reproduces the catalog-type error directly, while `REVOKE ALL PRIVILEGES ON ROUTINE probe.p()` succeeds.
- **影响**: Deployment/migration failure with complete transactional rollback when a procedure is present; the required complete procedure ACL reset/postcondition is not implemented. There is no demonstrated privilege escalation because the failure is fail-closed.
- **建议改法和验证点**: Use `ON ROUTINE` for the mixed `pg_proc` set, or split `prokind='f'`/aggregate/window functions from `prokind='p'` and use `ON FUNCTION`/`ON PROCEDURE` respectively. Within the exact 8-method IT budget, seed a procedure plus PUBLIC/query/command ACL residue in a bounded schema, replay V010 successfully, and assert no residual procedure ACL, zero PUBLIC/grant-option disclosure, and the intended role-effective denial.
- **修复风险（低/中/高）**: 低
- **严重程度（低/中/高/严重）**: 中
