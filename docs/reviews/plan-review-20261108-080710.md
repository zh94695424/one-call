## Open questions (non-blocking)

- **Replay fixture intent.** “Compatible fully migrated fixture” must be read as including V013 (the established V012 precedent), otherwise ordinary `flyway.migrate()` would apply V013 once rather than execute zero migrations. The plan's existing V012-admission pattern supports that reading; the implementation should make the fixture choice explicit in the role IT.
- **Role-absent ordering.** The database CREATE/TEMP and `pg_authid.rolpassword IS NULL` checks must run after the role exists (create the role first, or use a pre-created matching role). The plan's “Role absent means create it” and “before action” wording permits this; the implementation should not pass an absent role name to `has_database_privilege`.
- **Replay password reset.** Before re-executing V013, the transient probe password must be cleared to NULL so the existing-role password precondition holds; this mirrors the existing V012 admission IT.
- **ACL expansion filtering.** `aclexplode(relacl/attacl/nspacl)` must be scoped to the expected object/column/schema and grantee `evidence_media_reader_role`; the plans says “expected grantor/grantee”, and the role IT's 16 `pg_shdepend` rows are already reader-scoped.
- **Defensive `>1` mapping test.** V008's `uq_evidence_original_artifact` and PK joins make duplicate/ambiguous rows unreachable through PostgreSQL; the planned defensive mapping test should use a mocked/fake source, as previously accepted.
- **Nested `Result` variants.** To keep the 22-path allowlist, `Result`, `Found`, `Missing`, and `Unavailable` should be nested in `EvidenceMediaObjectReader.java`; the plan's API contract and allowlist imply this.
- **Matrix shorthand.** The matrix row “ownership/dependency” should be read as ownership/non-ACL dependency; the exact predicate in line 58 is authoritative and permits the 16 expected `deptype='a'` ACL rows. Likewise, “membership `p`” is not a `pg_shdepend` deptype on PG16 (membership lives in `pg_auth_members`, which the plan separately rejects); no operational impact.
