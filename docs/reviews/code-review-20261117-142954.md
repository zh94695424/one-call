## Findings (sorted by severity)

### PA35-S1-AGG-B-01 (Low) — no test pins the wire format of any `Instant` in the two new endpoints

- Category: test-strength / contract-regression gap. Blocking: no. Confidence: high.
- Location: `backend/src/test/java/com/onecall/archtests/OperationsIvrSessionReadWebTests.java:43`, `backend/src/test/java/com/onecall/archtests/OperationsIvrSessionReadWebTests.java:47`, `backend/src/test/java/com/onecall/archtests/container/OperationsIvrSessionReadsIT.java:231`, `backend/src/main/java/com/onecall/core/operations_iam/internal/web/OperationsIvrSessionReadController.java:29`.
- Condition: all 112 new PA35 identities assert JSON *property presence/absence* and
  identifier values, but never the serialized form of a timestamp. A grep of the eight
  new classes for any `path("<...>At")` value assertion returns only
  `guidanceStatus` (`OperationsIvrSessionReadsIT.java:292`); nothing compares
  `createdAt`, `confirmedAt`, `decidedAt`, `startedAt`, `answeredAt`, `endedAt` or
  `occurredAt` to an ISO-8601 string.
- Expected (frozen contract): `api/openapi/onecall-v1.openapi.yaml:4986` and `:5197`
  declare those fields `type: string, format: date-time`; the repo convention for that
  guarantee is an explicit value pin — see
  `backend/src/test/java/com/onecall/archtests/OperationsActivationReadWebTests.java:52`
  (`path("occurredAt").asString()).isEqualTo(facts.occurredAt().toString())`) and
  `backend/src/test/java/com/onecall/archtests/container/OperationsSubjectReadsIT.java:294`
  (`path("expiresAt").asString())`). No test anywhere validates live responses against
  the OpenAPI schema, so these per-slice pins are the only guard.
- Actual branch: correctness rests solely on the mapper construction
  `JsonMapper.builder().disable(DateTimeFeature.WRITE_DATES_AS_TIMESTAMPS)`
  (identical to the two sibling controllers), which under the pinned Spring Boot 4.1.2 /
  Jackson 3 toolchain emits ISO-8601 — so current behavior is correct; a future mapper,
  module or dependency change that emitted epoch numbers would be caught by zero PA35
  identities while the sibling read surfaces would fail loudly.
- Impact: contract `format: date-time` for the new endpoints is unguarded by regression
  evidence; asymmetric hardening versus the accepted convention. No runtime or security
  defect today.
- Fix direction (non-blocking, next test-only touch, existing identities): inside
  `exactListGetReturnsOnlyFrozenPageAndSummary` and `exactDetailGetReturnsOnlyFrozenSafeChain`,
  pin at least one ISO value per timestamp-bearing DTO (`createdAt`, `confirmedAt`,
  `decidedAt`, `startedAt`, `occurredAt`), reusing the fixture microsecond constant so the
  microsecond-precision invariant asserted by `instant()` is also exercised on the wire.
