## Open Questions

- **Empty `type` array (`type: []`)**: Redocly 1.34.3 accepts it (`a13-empty-type-array` exit 0) and the F5-01 predicate treats it as object-excluding. JSON Schema requires a non-empty unique type array, so this is an invalid-schema tooling gap rather than an accepted shape. It does not admit anything under a correct validator, but a lenient runtime could interpret it permissively. This matches the accepted F5-01 wording ("a type array without `object` suppresses the check"); decide whether to additionally require a non-empty type array. No canonical drift.
- **Dead `additionalProperties` with impure `$ref` under a non-object parent**: `type: string` + `additionalProperties: {$ref: ..., description: ...}` exits 0 (`a12`). This is intentional under fix-5 §7 ("no descent into dead `additionalProperties` when the parent type excludes objects") and is semantically correct; revisit only if a future contract places meaningful keywords under a non-object-typed `additionalProperties`.
- **Enum-only untyped request schemas**: `{enum: [A, B]}` now fails closure (`a4`). It is not object-admitting, so this is a fail-closed false rejection of a semantically safe shape; covered by the disclosed "untyped schemas must declare closure" policy, not a defect. Same class for annotation-only and composition wrappers.
- **Component-level boolean schema**: `FalseLeaf5: false` under `#/components/schemas` is rejected by Redocly `struct` (`a7`, exit 1), so a pure `$ref` chain ending at boolean `false` is not constructible in this toolchain. Boolean `false` inline at property/items positions remains allowed. Tooling boundary, fail-closed.
- **Explicitly deferred non-enumerated keywords**: `patternProperties` can re-open a closed object (`{type: object, additionalProperties: false, patternProperties: {'.*': {...}}}` exits 0, probe `a3`). This is the controller-deferred policy (`project-execution-control.md:232`; fix-5 §7) and is not reopened here, nor is `if/then/else`, `dependentSchemas`, `not`, `unevaluatedProperties`.
- **Finding 01 disposition**: the controller should choose between a bounded request-array closure fix and classification as an accepted latent residual with an owner. This review does not accept S1 or authorize a fix.
