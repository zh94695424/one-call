## 4. 已补充的产品决策

| 领域 | 已锁定决策 |
| --- | --- |
| 用户资格 | 仅支持持有效大陆居民身份证的用户；年龄政策待确认 |
| 实名 | 姓名和身份证二要素核验；高风险或公证场景可升级人脸活体 |
| 号码 | 个人手机号与独立固话合计最多三个；手机号用微信/短信验证，固话用运营商真实主叫验证；每号码独立授权和开通 |
| 固话范围 | 仅支持可返回唯一真实主叫的独立固话直线；企业总机、PBX、分机、统一外呼号拆分和坐席 PIN 暂不设计 |
| 公证资格 | 手机号申请线下公证书前强制三要素一致；固话按公证机构规则核验登记归属或合法使用权 |
| 授权 | 每个号码独立授权和开通；提交后同步返回成功/失败；协议实质变更后重新确认 |
| 取证入口 | 电话、相册照片/视频、现场拍摄、微信会话文件、聊天截图 |
| 微信能力 | 使用 `wx.chooseMessageFile`；不读取消息、联系人或完整聊天记录 |
| AI | 权益充足时固证后自动生成；带时间戳、说话人、置信度和引用 |
| 套餐 | 首次开通后累计 5 分钟免费录音电话；个人月/季/年订阅与加量包；企业基础/旗舰方案的价格、坐席、固话名额和权益由后台版本配置 |
| 用量 | 个人/组织额度按适用范围共享；流水必须记录实际主叫、号码类型、接入方式、证据和运营商会话 |
| 到期 | 原证据只读保留，暂停新增，不自动删除 |
| 公证处存证 | 所有五类原始证据在内部固证后自动提交 SHA-256 和最小元数据；收到 `recordNo` 才算成功 |
| 存证验证报告 | 以公证处返回任务和报告为准；报告验证存证记录/完整性，不等同于公证书 |
| 线下公证书 | 小程序创建申请工单，运营人员线下协调公证处；三要素不一致时阻止申请 |

- “可信时间”“不可篡改”“原始记录”等术语的最终对外定义。
