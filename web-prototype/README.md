# 一通话 · 证枢能力中枢 Web 原型

本目录是终端客户 Web 原型的唯一维护入口，覆盖个人用户工作台和企业用户工作台。

## 文件

- `evidence-hub.html`：原型源文件，所有页面与交互均在此维护。
- `preview.html`：运行 QA 后从源文件生成的浏览副本，不直接编辑。
- `qa/qa.js`：Playwright 交互、内容和响应式检查。
- `qa/run.ps1`：生成浏览副本并运行 QA。
- `qa/screenshots/`：各关键页面的评审截图。

## 运行

在 `D:\codex-call` 下执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\web-prototype\qa\run.ps1
```

运行成功后直接打开 `D:\codex-call\web-prototype\preview.html`。

预览默认进入登录页。微信扫码区域在原型中可点击模拟登录；手机号验证码演示值为 `482916`。登录页底部“原型评审”下拉框可切换二维码异常、首次隐私确认、企业邀请、会话过期、账户停用、成员移除和坐席未分配等状态。

## 当前范围

原型包含完整登录与身份承接、个人与企业两种工作空间、37 个业务路由视图和多类详情/向导页。登录部分覆盖微信扫码、手机号验证码、首次隐私确认、未实名开通引导、企业邀请、多工作空间选择、会话过期恢复和账号/成员/坐席异常。企业空间进一步提供企业管理员、普通成员、证据管理员和企业审计员四种评审视角。业务部分覆盖工作台、全类型证据箱、证据导入、通话录音与呼叫详情、受控录音分享与接收方播放、AI 转写摘要及版本管理、事情/事件档案、出证发起与补件、消息待办、号码、套餐与加量包购买、权益、订单、授权、下载导出，以及企业成员详情、坐席、部门、权限、组织设置和脱敏审计中心。

个人用户和企业管理员在左侧导航及顶部操作区均有套餐订阅入口。个人用户进入订阅、升级和购买流程；企业管理员进入订购、续费、扩容及方案变更。企业普通成员、证据管理员和审计员不显示该入口。

证据箱统一管理通话录音、照片、视频、现场录音、文件和聊天截图；通话录音另有专门列表，展示主叫、被叫、接入方式、呼叫结果、录音时长、AI 和存证处理状态。

录音分享采用受控播放授权：外部默认使用短期链接与独立提取码，支持指定手机号验证；企业内部可按成员授权。管理页覆盖有效、过期、撤销、延期和换码，接收方页面覆盖提取码错误锁定、播放副本、过期与撤销状态，不暴露原始存储地址。

事情档案已覆盖列表检索、两步新建、按权限选择已有证据、创建结果、证据增删关联、负责人调整、归档二次确认和只读状态；关联关系不会改变原始证据。AI 结果支持提交带原文位置的纠错建议、重新处理生成新版本、历史版本切换和版本对比，旧结果不可覆盖。出证申请支持补件选材、材料快照核对、提交、审核状态和进度记录。消息中心支持角色隔离、全部/未读/待处理筛选、单条与批量已读及业务跳转。

主叫号码已覆盖新增手机号/独立固话、微信或短信持有验证、运营商主叫验证、同步开通结果、三个号码上限、停用、删除、重新开通、公证资格和历史留存。协议与授权提供不可变快照、同意项、设备/IP、请求号、运营商回执、撤销和协议升级重新确认。

企业订购已形成“提交需求 → 后台报价 → 接受报价并生成合同 → 合同签署及权益生效”闭环；坐席、独立固话名额、价格和折扣均由后台商品版本及合同报价决定。企业成员的部门、角色和坐席变更包含前后值核对、明示确认、生效和审计记录，且不改变历史证据、用量归属或录音播放授权。个人录音、AI 和存储加量包支持后台商品规格、订单确认、支付、发放和订单快照。下载与导出已覆盖用途、范围、脱敏、二次验证码、准备中、可下载、部分失败、链接失效和重新申请，原始证据不因导出而改写。

自动化 QA 当前覆盖登录/会话、业务交互、六类证据详情、号码生命周期、授权换版与撤销、企业订购、下载导出、录音分享、AI 版本、事情维护、出证补件、消息待办、成员变更、加量包、角色授权和响应式检查，并生成 68 张关键视图截图。套餐页中的价格和折扣是评审演示值；生产环境必须使用服务端发布的商品版本和订单快照。

原型中的“视角预览”仅用于产品评审。生产环境的企业角色必须由服务端会话和授权策略决定，不能由用户在前端任意切换。

## 明确排除

- 平台运营台是独立产品面，不属于本原型。
- 企业总机、PBX、分机归属、统一外呼号拆分和坐席 PIN 不属于本期。
- 原型中的业务数据用于评审，不代表生产环境真实数据或已确认报价。
