# 一通话平台运营后台原型

本目录是平台员工运营后台的独立原型，不复用终端客户 Web 的企业空间、成员角色或租户授权模型。

## 文件

| 路径 | 用途 |
| --- | --- |
| `onecall-operations-admin.html` | 唯一原型源文件 |
| `preview.html` | QA 运行时从源文件生成的浏览副本，不直接编辑 |
| `qa/qa.js` | Playwright 权限、工作流、文案和响应式检查 |
| `qa/run.ps1` | 生成预览并执行 QA |
| `qa/screenshots/` | 自动化生成的关键评审截图 |

## 运行

在 `D:\codex-call` 下执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\operations-prototype\qa\run.ps1
```

运行成功后打开 `D:\codex-call\operations-prototype\preview.html`。原型完全本地运行，不连接真实身份源、供应商、支付、公证或对象存储服务。

## 当前范围

- 独立平台员工登录、二次验证状态和会话异常。
- 10 类平台角色和对象范围评审，不允许终端客户角色切换进入后台。
- 55 个计划路由，按 P0/P1/P2 逐步交付。
- 高敏字段和录音默认不可见；临时访问绑定工单、目的、对象范围、审批、二次验证和到期清除。
- 所有人工写操作以受控领域命令表达，不直接修改数据库、终态、余额或历史记录。
- 1024、1280、1440 三档桌面视口 QA。

## 评审数据

全部姓名、证件、号码、企业、订单、工单和供应商数据均为虚构内容。演示验证码只用于自动化测试，不代表生产二次验证方案。原型中的角色和场景选择器仅用于评审，生产系统必须由服务端会话决定角色、范围和对象权限。

## 维护规则

1. 只修改 `onecall-operations-admin.html`，不要直接修改 `preview.html`。
2. 新增或删除路由时同步更新路由注册表、导航、角色权限和 `qa/qa.js`。
3. 涉及敏感访问、状态机或人工命令时，必须同时增加允许和拒绝用例。
4. 未经正式规则确认，不写死 break-glass、审批阈值、退款、发票红冲、线下公证时限或供应商 SLA。
5. 不把“内部固证”“公证处存证”“存证验证报告”和“公证书”混为同一状态。
