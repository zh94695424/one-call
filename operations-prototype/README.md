# 一通话平台运营后台原型（精简版）

本目录是平台员工运营后台的独立原型，不复用终端客户 Web 的企业空间、成员角色或租户授权模型。

## 文件

| 路径 | 用途 |
| --- | --- |
| `onecall-operations-admin.html` | 唯一原型源文件 |
| `preview.html` | QA 运行时从源文件生成的浏览副本，不直接编辑 |
| `qa/qa.js` | Playwright 权限、工作流、文案和响应式检查 |
| `qa/run.ps1` | 生成预览并执行 QA |
| `qa/screenshots/` | 自动化生成的关键评审截图 |

## 运行

在 `D:\codex-call` 下执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\operations-prototype\qa\run.ps1
```

运行成功后打开 `D:\codex-call\operations-prototype\preview.html`。原型完全本地运行，不连接真实身份源、供应商、支付、公证或对象存储服务。

## 当前范围

- 当前业务依据为 [09 业务开通与精简后台](../docs/09-business-activation-and-lean-admin.md)，替代旧 55 路由、十角色版本。
- 面向 5 人团队：管理员、运营人员两类权限，13 个业务路由。
- 用户查询/暂停恢复、业务开通查询、IVR 会话、套餐新版本/上下架、试用规则、订单查询、操作记录与后续规划。
- 自建 IVR 呼入按键开通，未实名可试用并产生录音证据；号码业务主体待认领，验证认领不改变实名、不重发试用、不改写证据主体。
- IVR 只做购买引导，小程序和 Web 完成订购支付。支付与权益分列，历史订单和已发试用保留快照。
- 工单、退款、发票仅列规划，由线下人工客服支持；本期无执行入口。无原始录音、完整证件查看/播放功能。
- 原型评审抽屉可演示 IVR 新呼入、重复呼入、未确认、主叫缺失与认领冲突；纯内存模拟，刷新重置。无真实线路、短信或支付能力。
- 正常、空数据、加载中、服务不可用状态均可评审。
- 1024、1280、1440 三档桌面视口和 720 CSS 像素（200% 等效）视口 QA。

`qa/screenshots/lean-*.png` 是当前精简版截图；旧 `p0/p1/p2-*` 图片仅保留历史评审，不代表本期范围。小程序和客户 Web 原型此次未修改，仍需后续按新业务基线更新。

## 评审数据

全部姓名、号码、用户和订单数据均为虚构内容；金额为示例。演示验证码只用于评审，不代表生产身份验证方案。角色、场景和验证认领演示不代表生产鉴权，生产系统必须由后端验证可信主叫、身份、权限和认领凭证。原型不证明并发事务、短信送达、限时挂断或支付接入。

## 维护规则

1. 只修改 `onecall-operations-admin.html`，不要直接修改 `preview.html`。
2. 新增或删除路由时同步更新路由注册表、导航、角色权限和 `qa/qa.js`。
3. 涉及敏感访问、状态机或人工命令时，必须同时增加允许和拒绝用例。
4. 套餐修改创建新版本；试用规则只影响后续首次领取。不要增加工单前置条件、财务操作或复杂审批。
5. 不把“内部固证”“公证处存证”“存证验证报告”和“公证书”混为同一状态。
